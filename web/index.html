Executive Abstract

High-frequency time series frequently exhibit multiple simultaneous seasonal cycles, such as diurnal (24h) and circaseptan (168h) periodicities. Classical Seasonal-Trend decomposition using LOESS (STL) is restricted to a single seasonal period, leaving unmodelled periodic variations in the remainder component. In this research project, we study, implement, and extend the Multiple Seasonal-Trend decomposition using LOESS (MSTL) algorithm proposed by Bandara, Hyndman, and Bergmeir (2021).

We contribute: (1) a faithful Python implementation of Algorithm 1, verified to achieve exact mathematical reconstruction ($\max |X - \hat{X}| = 0.00$); (2) an exact reproduction of the Victoria electricity-demand experiment using 3,601 hourly observations with daily ($m_1=24$) and weekly ($m_2=168$) seasonal cycles; (3) an objective component-wise accuracy benchmark on synthetic data with known ground-truth components; and (4) four original research extensions: seasonal window sensitivity, multi-seasonality ablation, outlier and missing data robustness, and computational scalability profiling.

MSTL Algorithm & Mathematical Formulation

MSTL models the additive decomposition of time series $X(t)$ with $K$ seasonal components:

$$X(t) = \sum_{k=1}^K S_k(t) + T(t) + R(t), \quad t = 1, \dots, n$$
1

Period Filtering

Discards any candidate period $m_k$ where $2m_k \ge n$. A period must have at least 2 complete cycles to be identifiable.

2

Ascending Sorting

Sorts periods strictly ascending: $m_1 < m_2 < \dots < m_K$. High-frequency diurnal cycles are resolved before slower circaseptan cycles.

3

Iterative Back-fitting

Sequentially de-seasonalizes the series $\tilde{X}_k(t) = X(t) - \sum_{j \neq k} S_j(t)$ and fits standard STL at period $m_k$.

4

Exact Remainder

Calculates remainder algebraically $R(t) = X(t) - T(t) - \sum S_k(t)$, guaranteeing zero reconstruction drift.

Four Original Research Extensions

Original methodological extensions formulated and evaluated by our research team beyond the assigned paper.

Extension 1

Seasonal Window & Iteration Sensitivity

Evaluated odd LOESS windows $n_s \in \{7, 11, 15, 21, 25\}$ across outer iterations $I \in \{1, 2, 3\}$. Proved that mathematical reconstruction remains exact ($< 10^{-13}$) regardless of window choice, while runtime scales strictly linearly with iterations.

Runtime Grid: 0.10 s ($I=1$) → 0.31 s ($I=3$)
Extension 2

Multi-Seasonality Ablation Study

Compared Daily-only ($m=24$), Weekly-only ($m=168$), and Dual ($m=[24, 168]$). Demonstrated that modeling weekly seasonality alone inflates remainder standard deviation to $861.03$ MWh, while dual MSTL correctly isolates both periodicities ($809.77$ MWh).

Residual Std: 861.03 MWh → 809.77 MWh
Extension 3

Outlier & Missing Data Robustness

Discovered a crucial asymmetry: linear interpolation withstands up to 10% missing data with only 0.89% trend distortion, whereas 10% artificial outlier spikes inflict 33.56% trend degradation, proving the necessity of robust outlier preprocessing.

Missing Degradation: ≤ 0.89% (Highly Resilient)
Extension 4

Computational Scalability Profiling

Empirically measured runtime and memory consumption across dataset lengths from 168 hours (1 week) to 3,601 hours (5 months). Proved strict linear $O(n)$ scaling ($R^2 > 0.998$) with peak memory consumption staying under 0.75 MB throughout.

Runtime Scaling: $O(n)$ Linear (3 ms → 234 ms)
